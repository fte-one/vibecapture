## VibeCapture 1.0.1

**Verständliche Fehlermeldungen beim Hochladen**
- Statt „HTTP 403 (AccessDenied)“ sagt VibeCapture jetzt, was los ist und was du prüfen kannst. Ein Beispiel: „Zugriff verweigert – Cloudflare erkennt den Schlüssel, aber dieser R2-API-Token darf nicht in den Bucket schreiben“, dazu die Punkte zum Prüfen (Berechtigung „Object Read & Write“, Bucket im Bereich des Tokens, Ablaufdatum, IP-Filter).
- Eigene Erklärungen gibt es auch für eine unbekannte Access Key ID, einen falschen Secret Access Key, einen fehlenden Bucket, eine abgelehnte Anmeldung, einen nicht gefundenen Server, eine falsch gehende Mac-Uhr und Störungen beim Speicherdienst.
- Haben Account-ID, Access Key ID oder Secret Access Key eine untypische Länge, nennt die Meldung das gleich mit. Ein häufiger Fehler ist zum Beispiel, den Token-Wert statt der Access Key ID zu kopieren.
- **„Sichern & Verbindung testen“** prüft jetzt auch, ob die Testdatei unter der öffentlichen URL abrufbar ist. Klappt das Hochladen, aber nicht der Link, sagt die App das ausdrücklich.
- Die Meldungen erscheinen in den Einstellungen vollständig und lassen sich markieren und kopieren. Beim Hochladen zeigt die Einblendung Ursache und Hinweis.
